# outputs/

Files generated by the scripts (tables, fitted models, intermediate results).

## What goes here
Everything that can be re-created by running the scripts in `scripts/`. These files are
generally not committed (see `.gitignore`), so this folder may look empty after cloning.

## Main outputs

| File | Created by | Description |
|---|---|---|
| `[name]` | `scripts/[name]` | [short description] |

## Notes
- To keep a result in the repository (for example a table used in the article), say so in
  this README and make sure `.gitignore` does not exclude it.
