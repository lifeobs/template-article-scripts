# functions/

Reusable functions called by the scripts in `scripts/`.

> **Optional folder:** if your analyses use no custom functions, delete this folder.

## Contents

| File | Function(s) | Description |
|---|---|---|
| `[name]` | `[function_name()]` | [what it does, inputs, output] |

## Good practice
- Put here any code used by more than one script, instead of copying it.
- Describe each function in a short comment at its top: purpose, arguments, returned value.
- Functions should not depend on your own computer (no absolute paths).
